# FE 도메인 문서

각 도메인의 사용자 흐름, 핵심 개념과 상태 규칙을 설명합니다. 파일과 컴포넌트 목록보다 코드만 보고 파악하기 어려운 비즈니스 동작을 중심으로 관리합니다.

## 도메인 목록

| 도메인      | 책임                                          | 문서                               |
| ----------- | --------------------------------------------- | ---------------------------------- |
| 인증        | 회원가입, 로그인, 로그아웃과 세션 만료 처리   | [인증](./auth.md)                  |
| 채팅        | AI 스타일리스트 대화, 메시지 생성과 상품 추천 | [채팅](./chat.md)                  |
| 피팅        | 피팅 후보 관리, 착장 선택과 가상 피팅 작업    | [피팅](./fitting.md)               |
| 회원·프로필 | 서비스 접근 상태, 기본 정보와 전신 사진       | [회원·프로필](./member-profile.md) |

## 도메인 관계

```text
인증
 └─ 회원 상태 확인
     └─ 프로필 등록 및 조회
         ├─ 채팅 개인화
         └─ 가상 피팅의 체형·전신 사진

채팅 상품 추천
 └─ 피팅 후보 등록
     └─ 가상 피팅 작업
```

- 인증 성공 후 회원의 프로필 완료 여부에 따라 채팅 또는 프로필 등록으로 이동합니다.
- 채팅의 추천 상품을 피팅 후보에 추가하고 피팅 화면에서 바로 선택할 수 있습니다.
- 프로필의 체형 정보와 전신 사진은 가상 피팅 입력으로 사용됩니다.

## 관리 기준

- 사용자 흐름, 상태 전이, 입력 제약과 도메인 간 연동이 변경되면 관련 문서를 함께 수정합니다.
- Endpoint의 전체 명세를 복제하지 않고 FE가 사용하는 Method, Path와 역할만 기록합니다.
- 단순한 컴포넌트 구조 변경은 도메인 동작에 영향이 없으면 기록하지 않습니다.
- 아직 구현하지 않았거나 합의되지 않은 내용은 현재 동작과 구분해 보류 항목에 기록합니다.
