# 회원·프로필 도메인

마지막 업데이트: 2026-10-02

## 목적

로그인한 사용자의 서비스 이용 가능 상태를 확인하고, 추천과 가상 피팅에 필요한 기본 정보와 전신 사진을 등록·조회합니다.

## 도메인 구분

- **Member**: 현재 사용자의 프로필 완료 여부만 제공하며 서비스 Route 접근 제어에 사용합니다.
- **Profile**: 이메일, 이름, 나이, 키, 몸무게, 전신 사진과 가격 알림 설정을 제공합니다.
- **Full-body Image**: Profile 등록 전에 전신 사진의 파일 조건과 촬영 적합성을 검증합니다.

현재 Full-body Image는 독립 화면이 아니라 Profile 등록과 Fitting의 전제 기능입니다.

## 화면과 경로

| Path             | 역할                            |
| ---------------- | ------------------------------- |
| `/profile/setup` | 최초 기본 정보와 전신 사진 등록 |
| `/mypage`        | 등록된 프로필 확인과 로그아웃   |

프로필을 완료하지 않은 사용자가 일반 서비스 화면에 접근하면 `/profile/setup`으로 이동합니다. 완료한 사용자가 `/profile/setup`에 접근하면 `/chat`으로 이동합니다.

## 프로필 등록 흐름

1. 이름, 나이, 키와 몸무게를 입력합니다.
2. 전신 사진을 선택하면 먼저 브라우저에서 형식과 크기를 확인합니다.
3. `POST /full-body-image/validate`로 촬영 적합성을 검증합니다.
4. 검증된 `validationId`와 입력값, 가격 알림 설정으로 `POST /members/me/profile`을 요청합니다.
5. 성공하면 프로필 Query를 무효화하고 완료 화면을 표시합니다.
6. 1.7초 후 회원 상태 Cache를 완료로 바꾸고 `/chat`으로 이동합니다.

전신 사진 검증을 완료하지 않으면 Profile을 제출할 수 없습니다.

## 입력 규칙

| 항목           | 규칙                                                  |
| -------------- | ----------------------------------------------------- |
| 이름           | 앞뒤 공백을 제거한 1~10자, 한글·영문·숫자·공백만 허용 |
| 나이           | 만 나이 기준 정수, 1~100                              |
| 키             | 숫자, 100~250cm, 소수점 첫째 자리까지 입력 가능       |
| 몸무게         | 숫자, 30~200kg, 소수점 첫째 자리까지 입력 가능        |
| 가격 하락 알림 | 기본값 활성화                                         |

나이, 키와 몸무게 입력은 숫자와 소수점 입력만 남기도록 정리합니다. 나이는 정수로 검증하고, 키와 몸무게는 소수점 첫째 자리까지 허용합니다. API 요청 시 모두 숫자로 변환합니다.

## 전신 사진 규칙

### 브라우저 검증

- 확장자: JPG, JPEG, PNG
- MIME Type: JPEG, PNG 또는 Browser가 제공하지 않은 빈 값
- 최대 크기: 10MB

### 서버 검증

사진 검증 요청에는 60초 Timeout을 적용합니다. 서버 Error Code를 다음과 같은 사용자 행동 중심의 메시지로 변환합니다.

- 파일 없음, 지원하지 않는 형식, Decode 실패 또는 낮은 해상도
- 파일 크기 초과 또는 너무 어두운 사진
- 사람을 찾지 못함, 여러 사람 또는 사람이 너무 작게 촬영됨
- 전신, 양팔, 양다리가 보이지 않거나 정면이 아님
- AI Server 연결 실패, Timeout 또는 System Error

촬영 가이드는 한 사람의 머리부터 발끝까지 정면으로 촬영하도록 안내합니다. File Picker가 취소되거나 Camera 권한이 거부된 경우에도 구분된 메시지를 표시합니다.

## 프로필 조회와 활용

회원 상태와 Profile Query는 각각 5분의 `staleTime`을 사용합니다.

- 채팅: 첫 화면의 사용자 이름 개인화
- 피팅 홈: 등록한 전신 사진과 키·몸무게 표시
- 피팅 진행·결과: 사용자 이름과 체형 기준 표시
- 마이 페이지: 이메일, 이름, 나이, 키와 몸무게 표시

마이 페이지에서 Profile 조회가 실패하면 현재 화면에서 다시 시도할 수 있습니다.

## API

| Method | Path                        | 역할                  |
| ------ | --------------------------- | --------------------- |
| `GET`  | `/members/me`               | 프로필 완료 여부 확인 |
| `GET`  | `/members/me/profile`       | 현재 Profile 조회     |
| `POST` | `/members/me/profile`       | 최초 Profile 등록     |
| `POST` | `/full-body-image/validate` | 전신 사진 적합성 검증 |

## 관련 코드

- `src/features/member`: 회원 상태 API와 Schema
- `src/features/profile`: Profile 등록·조회와 화면 UI
- `src/features/profile`: Profile 등록과 전신 사진 선택·검증·촬영 가이드
- `src/shared/utils/profile-validation.ts`: Profile 입력 검증
- `src/app/(service)/(standalone)/profile/setup`: 등록 Route
- `src/app/(service)/(main)/mypage`: 조회 Route
