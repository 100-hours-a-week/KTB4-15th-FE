# 알림

알림 화면은 `GET /notifications`로 가상 피팅 성공·실패 알림 전체를 조회합니다.

- 성공 알림은 코디명과 결과 확인 동선을 제공합니다.
- 성공 알림을 선택하면 `/fitting/jobs/{fittingJobId}/result`로 이동합니다.
- 실패 알림은 고정 실패 문구만 표시합니다.
- 개별·전체 읽음 처리 성공 시 서버 응답의 `unreadCount`로 목록과 헤더의 읽지 않은 알림 여부를 갱신합니다.

서비스 레이아웃에서 인증과 병렬로 Next 서버가 사용자 쿠키를 전달하여 `GET /notifications/unread`를 조회합니다. 사용자별 응답은 `no-store`로 캐시하지 않고 클라이언트 쿼리 초기값으로 전달해 아이콘과 배지를 처음부터 함께 표시합니다. 초기값이 있으면 마운트 직후 중복 조회하지 않습니다. 알림 요청은 최대 1초만 기다리며, 실패하거나 시간 초과되면 화면을 열고 브라우저에서 재조회합니다. 이 경우 배지 없는 아이콘을 먼저 표시합니다. 창 복귀·네트워크 재연결 시 재조회하고, 내부 탭 이동별 조회와 폴링은 하지 않습니다.

로그인한 사용자는 서비스 영역에서 하나의 SSE 연결을 유지합니다.

- `connected` 이벤트로 읽지 않은 알림 여부를 초기화합니다.
- `notification` 이벤트로 가상 피팅 성공·실패 토스트와 헤더 아이콘을 갱신합니다.
- SSE 수신 시 알림 목록은 다시 조회하지 않습니다.
- 연결이 종료되면 3초 뒤 다시 연결하고, 서비스 영역을 벗어나면 연결을 정리합니다.

알림 아이콘은 `/chat`, `/wishlists`, `/fitting`, `/ranking`, `/mypage`의 헤더에 표시합니다.
