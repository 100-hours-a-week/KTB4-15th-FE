# 랜딩 화면

## 범위와 구성

`/landing`은 서비스 소개 시안입니다. 실제 채팅 API, 사진 업로드나 피팅 요청을 실행하지 않습니다. 기존 `/`와 `/onboarding` 진입 정책은 유지합니다.

헤더 → 히어로 → 기능 소개 → FAQ → CTA·푸터 순서로 구성합니다. 시작 링크는 `/signup`, 로그인 링크는 `/login`으로 연결합니다. AI 제작 사진과 전용 3D 일러스트를 사용합니다.

## 히어로

- 하나의 폰 안에서 채팅 → 초록 니트 추천 → 피팅 처리 → 동일 니트 착장 결과로 이어집니다. 가상 피팅 화면에는 뒤로가기 아이콘을 표시하지 않습니다.
- 추천 카드의 입어보기 강조 후 니트 이미지 영역이 피팅 사진 크기로 확장됩니다. 처리 표시를 거쳐 착장 사진과 상품 설명을 함께 보여줍니다.
- 세로 스크롤 2600px에 연동하고 `scrub: 0.6`으로 전환합니다.
- 화면 높이에서 헤더 공간을 제외해 히어로 높이를 정합니다. ResizeObserver로 폰이 들어갈 실제 스테이지 높이를 측정하고 최대 원래 크기까지 비율대로 축소합니다. 데스크톱의 짧은 창에도 적용합니다.
- 높이 740px 이하 모바일에서는 제목과 여백도 줄입니다. 니트 전환 좌표는 축소 전 좌표로 환산해 추천 카드와 착장 영역에 맞춥니다.

## 기능 소개

찜 기반 코디 추천(찜 10개 이상), 찜순·조회순 랭킹, 피팅 완료 알림을 소개합니다.

세로 스크롤에 따라 소개 3장이 왼쪽으로 이동합니다. 각 장은 중앙에서 750px 동안 머무르고 장면 사이는 900px 동안 이동합니다. 전체 구간은 4050px입니다.

찜 이미지는 정적으로 표시하며 왕관과 알림 벨은 해당 장면 최초 진입 시에만 움직입니다.

## FAQ와 마지막 영역

- FAQ는 네 가지 질문을 기본 HTML details/summary로 제공합니다. 키보드 조작을 유지하고 지원 브라우저에서는 높이·투명도를 300ms 동안 전환합니다. 미지원 브라우저에서는 즉시 열고 닫습니다.
- FAQ는 최소 100svh 높이에서 내용을 세로 중앙 정렬하고 답변이 늘어나면 영역도 늘어납니다.
- CTA와 푸터 묶음은 최소 100svh를 채웁니다. CTA는 연한 초록, 푸터는 FAQ와 같은 아이보리 배경과 상단 구분선으로 영역을 구분합니다. FAQ와 CTA에는 스크롤 고정을 적용하지 않습니다.
- 푸터에는 작은 브랜드명, 문의 이메일과 AI 연출 이미지 안내를 표시합니다. 모바일에서는 세로로 배치합니다.

## 모션 감소와 검증

모션 감소 설정에서는 스크롤 고정과 폰 축소를 적용하지 않습니다. 채팅과 착장을 함께 세로로 표시하고 기능 소개도 세로로 펼칩니다. FAQ는 즉시 개폐합니다.

`tests/e2e/landing.spec.ts`에서 스크롤 전환, 최초 진입 애니메이션, FAQ 키보드 조작, 모션 감소 배치와 짧은 모바일·데스크톱 화면의 폰 표시 및 피팅 정렬을 검증합니다. 실제 기기에서의 성능 측정은 별도입니다.

CTA와 푸터는 각각 `landing-cta.tsx`, `landing-footer.tsx`와 전용 SCSS Module로 분리합니다. 두 영역의 최소 화면 높이를 관리하는 closing 레이아웃은 `landing-screen`에 둡니다.
